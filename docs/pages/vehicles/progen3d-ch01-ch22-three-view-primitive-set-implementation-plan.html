2. Current-State Gap

Reading guide: this source section records “2. Current-State Gap”. Distinguish stated behavior from proposed or pending work using the status styling.

The current assembly intentionally uses the smallest valid existing operators:

CH01       ShellOffset(SurfaceLoft(...))
CH02-CH18 SweepProfile(constant RoundedRect, three-point path)
CH19-CH22 ShellLoft(four circular annular sections)

This proves semantic ownership, dimensions, placement, connection graphs, triangle realization, and GL46 rendering. It does not reproduce most visible:

variable sections
open thin-wall channels
multi-cell rocker construction
formed floor steps
pressed beads and ribs
local bosses
lightening openings
end flanges and joint pads
tower collars and mounting flanges
radial bolt-hole patterns

The implementation must fix these missing capabilities in FGKv1 rather than introducing one mesh builder per automotive part.

The phrase "90% closer" is normalized as a measurable 90% reference fit. No improvement percentage may be claimed without retaining the baseline score.

3.1 Per-view hard gates

Reading guide: this source section records “3.1 Per-view hard gates”. Distinguish stated behavior from proposed or pending work using the status styling.

For every CH part and every declared orthographic view:

silhouette intersection-over-union >= 0.90
95th percentile contour distance    <= 0.015 view diagonal
principal dimension residual        <= declared tolerance
visible feature recall              >= 0.90

Every view must pass independently. An average cannot hide a failed view.
