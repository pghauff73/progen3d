Surface partition

Reading guide: this source section records “Surface partition”. Distinguish stated behavior from proposed or pending work using the status styling.

Every face receives exactly one base panel owner and optionally one aperture owner. Apertures override base panel ownership in the resolved ledger:

[ O(f)=\begin{cases} A(f),&A(f)\neq\varnothing\ P(f),&\text{otherwise.} \end{cases} ]

Wheel pose

Reading guide: this source section records “Wheel pose”. Distinguish stated behavior from proposed or pending work using the status styling.

For steer (\delta) and suspension travel (j), each wheel receives a finite rigid transform with derived centre, camber and toe. A real elliptical-section tyre mesh is transformed through the sampled pose grid. The sweep envelope is the convex hull of all transformed tyre vertices.

Closure transform

Reading guide: this source section records “Closure transform”. Distinguish stated behavior from proposed or pending work using the status styling.

A revolute closure uses

[ T(q)=T(p)R_{\hat a}(q\theta_{max})T(-p),\qquad q\in[0,1]. ]

Bonnet and hatch systems add a small evidence-labelled rise translation.

Helical side glass

Reading guide: this source section records “Helical side glass”. Distinguish stated behavior from proposed or pending work using the status styling.

Door-local glass motion combines downward travel, inward motion, longitudinal shift and barrel-following rotation:

[ T_g(q)=T(\Delta xq,\Delta yq,-hq)R_x(\phi q). ]

The world transform is the parent-door transform multiplied by (T_g).
