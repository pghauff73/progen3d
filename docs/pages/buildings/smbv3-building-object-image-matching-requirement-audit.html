Certification Boundary

Reading guide: this source section records “Certification Boundary”. Distinguish stated behavior from proposed or pending work using the status styling.

This audit accepts the object model, test architecture, complete reference coverage, deterministic six-view baseline, and constrained front/right/top construction evidence. The constrained suite passes 108 of 108 objects, but it preserves ProGen3D geometry and transfers ImageGen appearance inside that geometry. It therefore does not certify freeform six-view equivalence.

Full visual certification still requires correction of all 48 six-view observability failures, activation of the planned semantic tests, all 108 objects passing every required six-view test, deterministic rerun evidence, and human semantic approval.
