The same gate compiles an independent calibration-evidence harness that verifies canonical JSON serialization, SHA-256 payload identity, immutable parsing and binding, order independence, domain-atomic deferral, readiness transitions, and rejection of duplicate, stale, unsupported, non-finite, mismatched, or contradictory evidence. That harness verifies raw source hashing, local coordinate and SI unit normalization, graph connectivity, chronology, accepted/deferred/rejected record reporting, exact adapter determinism, provenance and uncertainty propagation, Slice C round trips, and sequential readiness transitions for the five calibrated domains.
