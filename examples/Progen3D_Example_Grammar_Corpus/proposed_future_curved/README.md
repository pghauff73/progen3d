# Proposed curved primitive examples

These examples explore a later procedural curved-shape family. They are not supported by the current fixed-name `I(...)` parser.

The catalog covers:

- partial cylindrical azimuth sectors
- hollow cylindrical sectors
- chord-cut cylinders
- plane-clipped hemispheres
- hollow hemisphere bowls
- spherical caps

The proposed direction is to lower these shapes through a shared procedural-mesh / shape-specification layer rather than proliferating unrelated hard-coded mesh names.
