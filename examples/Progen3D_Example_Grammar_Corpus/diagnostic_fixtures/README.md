# Expected-invalid diagnostic fixtures

Every `.p3d` file in this directory is intentionally invalid. They are regression fixtures for parser, semantic-validation, expression, and runtime-preflight diagnostics.

They cover unsupported primitive names, delimiter errors, undefined symbols, invalid rotation axes, random-range errors, reserved `t`, section/alternate limits, arithmetic failure, rule arity, entry-rule parameters, invalid probability, missing instance appearance, and integer ranges containing no integer.
