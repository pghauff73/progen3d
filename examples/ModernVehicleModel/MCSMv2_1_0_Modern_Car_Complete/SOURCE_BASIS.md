# MCSMv2.1 Source Basis

MCSMv2.1 uses the MCSMv2.0.1 package, platform, style, wheel, suspension, powertrain, closure, parameter-evidence, and coordinate-frame records as its input basis. No new external package measurements were introduced in this patch.

The following are MCSMv2.1 implementation constructs rather than externally measured production geometry:

- no-wheelhouse implicit scaffold
- registered semantic surface
- periodic semantic UV domain
- panel-domain polygons
- aperture-domain polygons
- aperture support surfaces
- correspondence tolerances
- exclusive face-ownership policy

The model remains original concept geometry and does not reproduce proprietary production CAD.
