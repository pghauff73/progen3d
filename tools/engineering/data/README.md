# Quantity kind source data

The CSV derives from the QUDT community's [Quantity Kind Vocabulary 3.5.3](https://qudt.org/3.5.3/vocab/quantitykind) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It retains IDs, source URIs, English labels, dimension exponents and lifecycle status. Exponents are reordered to mass, length, time, electric current, temperature, amount and luminous intensity. Empty dimension columns represent the source's inapplicable dimension vector. This file does not designate approved engineering units or solvers.
