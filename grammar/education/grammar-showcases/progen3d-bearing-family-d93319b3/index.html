# ProGen3D | Bearing family 1.0.0 | Y-axis shaft, origin at the centre of the bearing.
# Change the Start rule to a named preset below, or call Bearing directly.
# Bearing(family bore outside width element count rollerLength front rear)
# Enter lengths in millimetres. Output geometry uses metres.
# family: 0 deep-groove ball, 1 cylindrical roller, 2 needle roller, 3 thrust ball, 4 plain sleeve.
# bore = shaft-hole diameter; outside = housing-seat diameter; width = axial width.
# element = ball or roller diameter; count = rolling elements in the single row.
# rollerLength = axial length for families 1/2; use zero for 68 percent of bearing width.
# front (+Y) and rear (-Y) are independent: 0 open, 1 metal shield, 2 elastomer seal.
# Use open faces for thrust and sleeve. Sleeve uses only bore, outside and width.
# The seven open ball sizes and the 625ZZ use NSK envelope dimensions, ball counts and ball diameters.
# Other families are illustrative examples. Pitch circle, ring profiles, cage and closures are schematic.
